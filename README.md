# US IT Recruiting Dashboard 🚀

A comprehensive, interactive recruitment tracking and performance analytics dashboard built in **Microsoft Excel**. Designed specifically for high-volume US IT staffing operations, this tool centralizes data for a team of 10 recruiters to monitor daily workflows, pipeline conversion rates, and individual target achievements.

---

## 📊 Key Features

* **Executive KPI Summary:** Instant visibility into core metrics including Submissions, Interviews, Placements, Rejections, Interview Rates, and Placement Rates[cite: 1].
* **Dynamic Interactivity & Slicers:** Filter data seamlessly by month, specific days, recruitment teams, and individual recruiters[cite: 1].
* **Trend Analysis:** Visual line charts tracking overall review trends, submission trajectories, and placement milestones over time[cite: 1].
* **Performance Leaderboards:** Built-in tracking for top technologies, top vendors, individual recruiter contributions, and team-vs-target metrics[cite: 1].

---

## 🛠️ Tech Stack & Skills Demonstrated

* **Advanced Excel:** Power Pivot, advanced formulas, conditional formatting, and data modeling.
* **Data Visualization:** Custom charts, KPI cards, and structured layout design.
* **HR & Recruitment Analytics:** Tracking recruitment funnel conversion metrics and team performance targets.
